ENVIAR ALTERAÇÕES PARA O GITHUB NA PASTA \LATEX
git add . && git commit -m "game 2" && git push

ORGANIZAR:
git add .
git rebase --continue
git push

OU SEMPRE QUE TROCAR DE AMBIENTE
git pull --rebase

SABER EM QUE PASTA ESTA
pwd



RODAR RÁPIDO SEM REFERÊNCIAS

cd /workspaces/Latex/IC-UFF
pdflatex -interaction=nonstopmode tese.tex


Completo (com referências e glossário):

cd /workspaces/Latex/IC-UFF
pdflatex tese.tex && biber tese && makeglossaries tese && pdflatex tese.tex && pdflatex tese.tex

SALVAR NO GITHUB

cd /workspaces/Latex
git add .
git commit -m "descreva o que fez aqui"
git push



puxar mudanças que fez no Windows via Trae/Notepad++:

cd /workspaces/Latex
git pull
cd IC-UFF
pdflatex tese.tex  # ou a compilação completa
